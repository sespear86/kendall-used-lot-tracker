# Kendall Used Lot Tracker

Sideload Android app for used + Certified Pre-Owned inventory at Kendall Subaru of Eugene.

## Latest download (v1.0.7)

**https://files.catbox.moe/ss4v4a.apk**

Direct APK. No Google account. Android 10+.

This build: days on lot (Pacific Time), min/max days-on-lot sliders, Clear filters at the top of Filters, buttons above the phone nav bar.

## In-app Update pipeline

Installed copies check:

https://raw.githubusercontent.com/sespear86/kendall-used-lot-tracker/main/release/latest.json

**Update app** appears only when that file’s `version_code` is **greater** than the app on the phone. If you already have 1.0.7, the button stays hidden — use the link above to reinstall.

Current descriptor: `version_code` 8 / `version_name` 1.0.7.
