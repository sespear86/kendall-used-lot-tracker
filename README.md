# Kendall Used Lot Tracker

Sideload Android app for used + Certified Pre-Owned inventory across Kendall rooftops in the Eugene area (Subaru, Honda/Acura, Toyota, Value Lot).

## Latest download (v1.0.9)

**https://files.catbox.moe/n1hu5u.apk**

Direct APK. No Google account. Android 10+.

This build: current listing price plus dated listing-price changes on vehicle detail, all Eugene-area Kendall lots with a dealership selector, days on lot (Pacific Time), min/max days-on-lot sliders, exclusive Certified chip, Clear filters at the top of Filters, buttons above the phone nav bar.

## In-app Update pipeline

Installed copies check:

https://raw.githubusercontent.com/sespear86/kendall-used-lot-tracker/main/release/latest.json

**Update app** appears only when that file’s `version_code` is **greater** than the app on the phone. If you already have 1.0.8, this 1.0.9 release should show the button.

Current descriptor: `version_code` 10 / `version_name` 1.0.9.

Telegram **#all-devices** also has the APK file and this same link.
